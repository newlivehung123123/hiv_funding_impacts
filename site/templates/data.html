Data and downloads

All compiled, curated and harmonised datasets developed in our project are made publicly accessible. In every dataset, a row is a single figure from a single source for a single country, indicator and year. Sources are not merged and duplicates are not removed, because the differences between sources are part of what the project is measuring. Where two sources report the same country and year, the two rows are alternative readings of the same figure and not two amounts to add, so any total has to be built from a single source at a time. The indicator tables below show which indicators have rows from two or more sources for the same country and year, and how many rows are affected.
